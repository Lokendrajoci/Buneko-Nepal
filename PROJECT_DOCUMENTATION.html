📋 Project Overview

Buneko Blooms - Handcrafted Flower E-Commerce

An e-commerce platform for handmade and sustainable flower products crafted by Nepali artisans. The platform enables customers to browse products, place orders, request custom bouquets, and provides comprehensive admin management capabilities.

🎯 Project Type

Database Tables

1. Users Table

Column Type Constraints Description
idINTPK, AUTO_INCREMENTUnique identifier
nameVARCHAR(100)NOT NULLFull name
emailVARCHAR(100)UNIQUE, NOT NULLEmail address
passwordVARCHAR(255)NOT NULLBcrypt hashed
roleENUM'customer','admin','superadmin'User role
phoneVARCHAR(20)NULLContact number
addressTEXTNULLShipping address
profile_image_urlVARCHAR(500)NULLProfile picture
is_activeBOOLEANDEFAULT TRUEAccount status
created_atTIMESTAMPDEFAULT NOW()Created date
updated_atTIMESTAMPON UPDATELast update

2. Categories Table

Column Type Constraints Description
idINTPK, AUTO_INCREMENTUnique identifier
nameVARCHAR(100)NOT NULLCategory name
descriptionTEXTNULLCategory details
image_urlVARCHAR(500)NULLCategory image
created_atTIMESTAMPDEFAULT NOW()Created date

3. Products Table

Column Type Constraints Description
idINTPK, AUTO_INCREMENTUnique identifier
nameVARCHAR(200)NOT NULLProduct name
descriptionTEXTNULLProduct details
priceDECIMAL(10,2)NOT NULLProduct price
category_idINTFK → categoriesCategory reference
image_urlVARCHAR(500)NULLProduct image
stockINTDEFAULT 0Available quantity
created_atTIMESTAMPDEFAULT NOW()Created date

4. Orders Table

Column Type Constraints Description
idINTPK, AUTO_INCREMENTUnique identifier
user_idINTFK → usersCustomer reference
total_amountDECIMAL(10,2)NOT NULLOrder total
payment_statusENUM'pending','paid','failed'Payment status
statusENUMVarious statusesOrder status
shipping_addressTEXTNOT NULLDelivery address
phoneVARCHAR(20)NOT NULLContact number
latitudeDECIMAL(10,8)NULLGPS latitude
longitudeDECIMAL(11,8)NULLGPS longitude
notesTEXTNULLOrder notes
created_atTIMESTAMPDEFAULT NOW()Order date

5. Order Items Table

Column Type Constraints Description
idINTPK, AUTO_INCREMENTUnique identifier
order_idINTFK → ordersOrder reference
product_idINTFK → productsProduct reference
quantityINTNOT NULLItem quantity
priceDECIMAL(10,2)NOT NULLPrice at purchase
subtotalDECIMAL(10,2)NOT NULLLine item total

6. Wishlist Table

Column Type Constraints Description
idINTPK, AUTO_INCREMENTUnique identifier
user_idINTFK → usersUser reference
product_idINTFK → productsProduct reference
created_atTIMESTAMPDEFAULT NOW()Added date

7. Customizations Table

Column Type Constraints Description
idINTPK, AUTO_INCREMENTUnique identifier
user_idINTFK → usersCustomer reference
titleVARCHAR(200)NOT NULLRequest title
descriptionTEXTNOT NULLRequirements
typeENUM'bouquet','arrangement'Customization type
occasionVARCHAR(100)NULLEvent/occasion
budgetDECIMAL(10,2)NULLBudget range
delivery_dateDATENOT NULLRequired date
statusENUMVarious statusesRequest status
admin_notesTEXTNULLAdmin comments
quoted_priceDECIMAL(10,2)NULLAdmin quoted price
created_atTIMESTAMPDEFAULT NOW()Request date

8. Contents Table

Column Type Constraints Description
idINTPK, AUTO_INCREMENTUnique identifier
titleVARCHAR(200)NOT NULLContent title
urlVARCHAR(500)NOT NULLContent URL (TikTok)
platformENUM'tiktok','instagram'Social platform
created_atTIMESTAMPDEFAULT NOW()Created date

🔌 API Endpoints

Authentication APIs

Method Endpoint Auth Description
POST /api/auth/register Public Register new customer
POST /api/auth/login Public User login
POST /api/auth/logout Required User logout
GET /api/auth/me Required Get current user
POST /api/auth/refresh Required Refresh JWT token

Product APIs

Method Endpoint Auth Description
GET /api/products Public List products (with pagination, search, filter)
GET /api/products/:id Public Get product by ID
GET /api/products/category/:categoryId Public Get products by category
POST /api/products Admin Create new product
PUT /api/products/:id Admin Update product
DELETE /api/products/:id Admin Delete product

Category APIs

Method Endpoint Auth Description
GET /api/categories Public List all categories
GET /api/categories/:id Public Get category by ID
POST /api/categories Admin Create category
PUT /api/categories/:id Admin Update category
DELETE /api/categories/:id Admin Delete category

Order APIs

Method Endpoint Auth Description
GET /api/orders Admin List all orders
GET /api/orders/my-orders Customer Get user's orders
GET /api/orders/:id Customer/Admin Get order by ID
POST /api/orders Customer Create new order
PATCH /api/orders/:id/status Admin Update order status
PATCH /api/orders/:id/cancel Customer Cancel order

Other APIs

Module Endpoints Description
Users /api/users User management (CRUD, profile update, status toggle)
Wishlist /api/wishlist Add/remove products to wishlist
Customizations /api/customizations Custom bouquet request management
Contents /api/contents TikTok/social content management
Payments /api/payments/create-checkout-session Stripe payment integration
Dashboard /api/dashboard/stats Admin dashboard statistics
